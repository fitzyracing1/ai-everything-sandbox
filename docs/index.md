# AI Everything (repo: ai-everything-sandbox)

The README describes a modular multi-agent framework: a subsumption priority stack (air → eat → win → talk), tool composition, ternary search trees, and a self-coder loop. It also lists a directory layout (`core/`, `agents/`, `tools/`, `simulations/`, `tests/`, ...).

**What is in the repo:** only `README.md` and `main.py`. `main.py` imports `core.runtime`, `agents.knowledge_agent`, `agents.simulator_agent`, `core.agent` and `tools.composer`, and none of those modules are committed. **The project cannot run from this repo as it stands.** The README's quick start (`cd /home/workdir/artifacts/ai-everything && python3 -m core.runtime --demo`) refers to the original sandbox path.

The README says the project was bootstrapped on 2026-07-31. The repo has no LICENSE file.
