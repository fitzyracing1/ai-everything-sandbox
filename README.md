# AI Everything

**Autonomous modular multi-agent AI framework built entirely inside the Grok sandbox.**

This project is the living response to the directive **"Build everything in AI"**.

It unifies concepts from the local skill ecosystem into one coherent, extensible, self-documenting, and self-improving system:

- **Subsumption Architecture** priority stack (Provide Air → Eat → Win → Talk)
- **Starfit-style** live header-grabbing tool composition
- **Ternary Search Trees** for efficient knowledge & string dictionaries
- **Persistent Self-Coder** monitoring and autonomous delivery loops
- Conceptual **BMD AI Agents** simulation modules (defensive research only)
- Transformer-inspired multi-modal agent personas
- Pure local execution (torch, numpy, scipy available)

## Design Goals

1. Everything runs offline inside this sandbox.
2. Every component is inspectable, testable, and extensible.
3. Priority of survival and mission always overrides communication.
4. The system can observe its own codebase and propose/deliver improvements.
5. New capabilities are composed rather than hard-wired.

## Directory Layout

```
ai-everything/
├── core/               # Fundamental abstractions (Agent, Subsumption, Runtime)
├── agents/             # Concrete agent implementations
├── tools/              # Composable tools (Starfit pattern)
├── simulations/        # Physics & multi-agent sims (BMD conceptual, etc.)
├── docs/               # Architecture notes, roadmaps
├── tests/              # Verification
└── logs/               # Runtime & self-coder activity
```
